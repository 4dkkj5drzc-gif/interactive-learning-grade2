# مختبر التعلّم التفاعلي – الصف الثاني الأساسي

نموذج أولي ثابت (Static Website) باللغة العربية، يتضمن:
- مكتبة بثلاثة كتب/مواد: أحب لغتي، ديني حياتي، والهوية والمواطنة.
- قارئ صفحات تفاعلي مع أزرار تنقل وأنشطة قصيرة.
- منصة ألعاب تعليمية بثلاثة أنماط تجريبية.
- تصميم متجاوب للهاتف واللوحي والحاسوب.

## التشغيل محليًا
افتح `index.html` في المتصفح. لا توجد حاجة إلى تثبيت حزم.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub باسم `interactive-learning-grade2`.
2. ارفع الملفات الثلاثة: `index.html`, `style.css`, `script.js` وملف `README.md`.
3. من المستودع اختر Settings ثم Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر `main` و`/(root)` ثم Save.
6. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.

## ملاحظة المحتوى
هذا نموذج توضيحي مبني على عناوين ومحاور ظاهرة في الكتب المرفقة. لا يُعد نسخة رقمية كاملة من الكتب الرسمية، ولا يستبدل النصوص أو الصور الأصلية. يلزم مراجعة كل نشاط مع المعلمة ومطابقة محتوى المادة الثالثة مع النسخة الرسمية المعتمدة قبل الاستخدام التعليمي الرسمي.


## تحديث التفاعل ثلاثي الأبعاد الأولي
- منظور ثلاثي الأبعاد لقارئ الصفحات مع حركة تقليب.
- عنصر بصري قابل للتدوير داخل الصفحة.
- زر قراءة النص بصوت المتصفح عند دعم العربية.
- التأثيرات الحالية CSS ثلاثية الأبعاد تجريبية وليست نماذج مجسمة تعليمية كاملة.
- النصوص الحالية أمثلة توضيحية وليست نسخًا حرفية من الكتب الرسمية. يلزم توفير نسخة PDF قابلة للقراءة من كتاب اللغة العربية لمطابقة الدروس.
