كتاب تفاعلي: درس لُعْبَتِي — الصف الثاني الأساسي

محتويات المشروع:
- index.html: صفحة الكتاب التفاعلي.
- assets/lesson-scene.mp4: فيديو المشهد الذي زودت به الطالبة (8 ثوانٍ).
- assets/lesson-scene.png: صورة احتياطية تظهر كغلاف قبل تشغيل الفيديو أو عند تعذر تحميله.

طريقة الرفع إلى GitHub Pages:
1. استبدلي ملف index.html في جذر المستودع.
2. ارفعي الملف assets/lesson-scene.mp4 داخل مجلد assets بالاسم نفسه.
3. احتفظي بملف assets/lesson-scene.png في المسار نفسه.
4. احفظي التغييرات عبر Commit changes وانتظري تحديث GitHub Pages.

ملاحظة:
الفيديو الحالي هو مشهد افتتاحي لسعاد بجانب الفلج. لا يتضمن بعد مشهد انفلات الدمية وانجرافها تحت القنطرة.
التسجيل الصوتي البشري غير مرفق في هذه النسخة.
