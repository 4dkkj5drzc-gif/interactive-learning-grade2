النموذج التجريبي للمكتبة التفاعلية — الصف الثاني

يحتوي على ملفات PDF الأصلية الثلاثة دون تعديل:
- أحب لغتي
- ديني حياتي
- أنا أشارك

طريقة التشغيل:
1. ارفعي كامل محتويات المجلد إلى مستودع GitHub Pages مع الحفاظ على مجلد books.
2. افتحي الموقع عبر GitHub Pages.
3. يتطلب عارض PDF.js اتصالاً بالإنترنت لتحميل مكتبة العرض من CDN.

الموجود في النموذج:
- مكتبة تعرض أغلفة الكتب.
- فتح كل كتاب من ملفات PDF الأصلية.
- تقليب الصفحات مع تأثير بصري ثلاثي الأبعاد.
- وضع منظور مجسّم تجريبي للكتاب.

غير المنجز بعد:
- المجسمات التعليمية الحقيقية الخاصة بكل درس والتفاعل معها. يجب إعدادها درساً درساً بعد استخراج عناصر كل صفحة؛ لم يتم الادعاء بأنها موجودة في هذه النسخة.
